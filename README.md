# htmlx

**An open question about the next document format, worked out in public.**

> Excel and Word are only HTML's "database".
> Human–AI collaboration will reach its best practice through HTML.

AI now writes documents faster than anyone can read them. We think people
shouldn't be reading raw AI output at all, any more than they read rows in a
database. AI works in structure and data. People look at, judge and adjust a
graphical, interactive HTML surface. Word layouts and slide decks stay for
formal occasions, as the place work is stored or exported, not where it
happens.

This is an intuition, not a spec. We haven't worked it out, and we'd like to
think it through with you.

## Join in

- **Discussions** — argue for it, against it, or sideways.
- **Your version** — rewrite the thesis, build a counter-example, or share an
  HTML document that proves or breaks the idea.

The interactive concept lives at [officedocs.io/lab](https://officedocs.io/lab)
(coming soon).

## A note on the name

Yes, [htmx](https://github.com/bigskysoftware/htmx) exists and is great. This
is unrelated. We kept the name because this is a discussion, not a product.
